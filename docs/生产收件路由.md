# Cloudflare Email Routing 配置

将你拥有的收件域名接入 Cloudflare Email Routing，并按需要配置 catch-all 规则，将邮件交给 MailHub Worker：

- 匹配到有效且未过期的 MailHub 临时邮箱时，Worker 解析邮件并写入 D1/R2。
- 未匹配到有效临时邮箱时，如需保留原有转发行为，Worker 将邮件转发到已验证的目的地址。
- `FALLBACK_EMAIL` 只保存在 Worker Secret 中，不要写入 Wrangler 配置、源代码或 Git。
- 修改规则前，确认 `FALLBACK_EMAIL` 已设置，且 Cloudflare Routing 的 catch-all 规则指向正确的 Worker。
- 原有 MX、SPF、DKIM 等 DNS 记录应按你的邮件服务商配置保留。

查看或回滚时，在 Cloudflare 控制台选择自己的域名，打开 **Email Routing → Catch-all**。回滚可以将动作改为 **Send to an email**，并选择此前验证过的目的地址。

当前 catch-all 通过 Cloudflare Email Routing 管理，不在 Wrangler 配置中声明 `addresses = ["*@your-domain"]`。避免后续部署尝试接管或重建已有规则。
