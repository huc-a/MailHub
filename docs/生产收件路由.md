# Cloudflare 生产收件路由

生产域名 `ear1.de5.net` 已接入 Cloudflare Email Routing。当前启用的全域规则将邮件交给 `mailhub` Worker：

- 匹配到有效且未过期的 MailHub 临时邮箱时，Worker 解析邮件并写入 D1/R2。
- 未匹配到有效临时邮箱时，Worker 将邮件转发到原来已验证的收件地址，保留之前的全域转发行为。
- 原有 MX、SPF、DKIM DNS 记录保留。

原转发目的地址只保存在 Worker Secret `FALLBACK_EMAIL`，不得写入 `wrangler.toml`、源代码或 Git。修改此规则前，先确认该 Secret 已设置：

```powershell
npx wrangler secret list
```

在 Cloudflare 控制台查看或回滚规则：**Compute → Email Service → Email Routing → ear1.de5.net → Catch-all**。回滚时，将动作改为 **Send to an email**，并选择此前使用的已验证目的地址。

当前 catch-all 是通过 Cloudflare Email Routing API 管理的，不在 Wrangler 配置中声明 `addresses = ["*@ear1.de5.net"]`。否则后续部署可能尝试接管或重建现有全域规则。
