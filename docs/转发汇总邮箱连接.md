# 转发汇总邮箱连接

MailHub 可以通过 IMAP 读取一个已接收其他邮箱转发邮件的汇总邮箱。这个连接与 Gmail OAuth 独立，不需要创建 Google OAuth Client；它使用汇总邮箱自身的 IMAP 应用授权码。

## 设置

1. 在汇总邮箱服务商开启 IMAP，并生成应用专用授权码。不要使用邮箱主密码。
2. 在 MailHub 打开 **偏好设置 → 转发汇总邮箱（IMAP）**。
3. 选择中转邮箱服务商，填写地址、IMAP 授权码，以及要读取的文件夹。默认读取 `INBOX`；每行可填写一个文件夹。
4. 点击“验证连接并保存”。服务端会先用 TLS 登录并检查文件夹，然后用 AES-GCM 加密授权码存入 D1。
5. 验证成功后会排入首次同步；之后 Cloudflare Cron 每分钟检查一次新邮件。

当前支持 QQ 邮箱和 Gmail IMAP 的 SSL 993 端口，最多配置 10 个文件夹。每轮总共最多读取 50 封，并在文件夹间分配额度以避免某个文件夹长期占用同步批次；首次同步读取各文件夹最近邮件，并跳过超过 180 天的邮件。后续使用 UID 与 UIDVALIDITY 作为每个文件夹的持久游标。

同步读取邮件时使用 IMAP `BODY.PEEK[]`，不设置远程已读标记。邮件内容进入 MailHub 的 D1/R2，邮件列表按 Gmail 来源展示。UI 本地已读状态与原邮箱状态相互独立。

`TOKEN_ENCRYPTION_KEY` 是加密密钥。不要删除或轮换它，除非准备让已连接的汇总邮箱重新填写授权码。项目的 `.dev.vars` 被 Git 忽略，保存了本地开发所需密钥；请为该文件保留安全备份。
